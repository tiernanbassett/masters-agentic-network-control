# Masters Dissertation - Agentic AI for Network Control

**Student:** Tiernan Bassett  
**Supervisor:** Merim Dzaferagic  
**Project Title:** Agentic AI Control of Wireless Networks Using an AI-Native Network Controller with Safety Guardrails

This dissertation investigates the use of agentic AI in network control. The project includes using the OCUDU platform along with an AI-Native Network Controller to support the use of closed-loop agentic control. It investigates the tradeoffs between reliability, latency, and agent autonomy. Safety is also a big focus, with safety mechanisms and guardrails being investigated.

The literature reviewed includes topics such as Agentic AI, Agentic Frameworks and Harnesses, Agentic AI in Networking, AI-Native Networking, Network Management. This literature aids the system design, architecture and setup.
